Gnostic Spark + Bridge Rise

Public overview · what the code actually does

Architecture doc

Two recall paths, both deterministic and privacy-aware. Spark is a rare spontaneous line. Bridge Rise only fires when at least two independent signals agree.

Gnostic Search is a BFS on the memory graph until paths converge. Spark ranks a cascade-first pool with Kuramoto coherence, a weighted logit, and ERIP privacy (P=5 never surfaces spontaneously; a candidate needs two cue types). Bridge Rise fires on any two of fragment, archival tag, and topic weather on the same theme. Climate is rank-only.

Spark: at most once per agent per cooldown (default 300 s). Bridge Rise: cooldown is per agent|channel (library and the demo simulate endpoint; ?force=1 skips it).
